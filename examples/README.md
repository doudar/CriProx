# Editable artwork examples

Open `skarix-aurora.skarix.json` from Skarix Home to explore the **Aurora** logo. It was created through Skarix's MCP server and contains ten editable layers: a rounded enamel badge, lighting, mint and coral chevrons, and lettering. It demonstrates multi-stop gradients, glows, inner/drop shadows, seeded grain and metal textures, and a paper texture on text. `skarix-aurora.png` is the rendered preview.

This is an example logo concept; it does not replace the application's icon.
